# 🐍 Python Fundamentals – Labs & Exercises

## 📖 About This Repository

This repository contains Python programming labs, exercises, and practical assignments completed as part of postgraduate studies in **Cloud Computing IT Solutions Architecture**.

The primary goal of this repository is to document the learning journey, strengthen Python programming fundamentals, and develop practical problem-solving skills applicable to real-world IT environments and cloud computing solutions.

## 🎯 Learning Objectives

The exercises and assignments focus on:

- **Python Fundamentals** – Understanding core programming concepts, syntax, data types, and control structures.
- **Data Structures** – Working with lists, tuples, dictionaries, and sets.
- **Functions and Modules** – Writing reusable, modular, and maintainable code.
- **File Handling** – Reading, writing, and processing files.
- **Error Handling** – Implementing exception handling and debugging techniques.
- **Problem Solving** – Developing logical thinking and algorithmic approaches.
- **Practical Applications** – Exploring how Python can support IT automation and cloud computing workflows.

## 📂 Repository Contents

The repository includes:

- **Labs** – Hands-on programming exercises covering fundamental Python concepts.
- **Exercises** – Coding challenges designed to reinforce theoretical knowledge.
- **Assignments** – Practical tasks demonstrating the application of Python programming skills.

**Field of Study:** Cloud Computing IT Solutions Architecture
